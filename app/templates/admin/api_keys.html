API Reference

Send an API key as Authorization: Bearer <key>. Every endpoint is scoped to this organization automatically. This is a plain REST API rather than native LTI — see the note at the top of app/api_v1.py for how to bridge it into an LTI-based Moodle/Canvas setup.
MethodEndpointPurpose
GET/api/v1/testsList published tests
GET/api/v1/tests/<test_code>Test detail
POST/api/v1/tests/<test_code>/enrollPush a roster (create-or-fetch students, grant eligibility)
GET/api/v1/tests/<test_code>/resultsPull results/grades, optionally ?since=<ISO timestamp>
GET/api/v1/students/<email>/attemptsOne student's attempts across all tests
